# FNIRSI DPS-150 新版上位机 · 使用说明

科技感 Web 版上位机，单文件、免安装。功能与协议 100% 逆向兼容官方 `数控电源上位机 v2.0.2.3`。

## 启动

**方式一（推荐）**：双击 `启动上位机.bat`

**方式二**：直接双击 `DPS150-控制台.html`（需系统默认浏览器为 Edge 或 Chrome）

> 必须使用 **Microsoft Edge** 或 **Chrome** 浏览器（需要 Web Serial 串口能力）。
> 页面从本地打开即可，无需联网。

## 连接设备

1. USB 线连接 DPS-150（会枚举出一个串口）
2. 波特率选择与设备一致的速率（默认 115200）
3. 点击 **联机** → 浏览器弹出串口授权，选中 DPS-130/150 对应端口
4. 状态灯变绿 = 联机成功，仪表盘开始实时刷新

> 首次授权过的端口会被浏览器记住，之后联机不再重复弹窗。
> 没有设备时：打开右上角 **演示模式** 再点联机，可体验全部功能（虚拟设备会持续推送数据）。

## 功能总览

| 页面 | 功能 |
|---|---|
| 仪表盘 | 电压/电流弧形仪表、输出开关、CV/CC 与保护状态、V/A 设定（步进即时下发）、计量 Ah/Wh、背光亮度、6 组快捷数据 |
| 曲线记录 | V/A 双通道实时曲线；开始记录后可导出 CSV（Excel 可直接打开） |
| 电压/电流扫描 | 恒流扫电压 / 恒压扫电流，起止/步进/间隔可设，进度条实时显示 |
| 自动序列 | 10 步序表 (V/A/延时)，循环次数与起止序号，开始/暂停/继续/停止/单步；表格自动保存在本机 |
| 保护/设备 | OVP/OCP/OTP/LVP/OPP 阈值读写、型号/固件/地址/上限等设备信息 |
| 固件升级 | 发送 BOOT 命令（F1 C0 00 01 01），随后按提示用U盘升级 |

底部 **CONSOLE** 显示所有串口原始帧（TX/RX 十六进制），可用于排查通信问题。

## 与官方上位机的差异

- 界面全新（深色科技风），交互更直接：步进按钮一点即下发
- 曲线导出为 CSV（官方为 Excel 插件导出）
- 自动序列步序表保存在浏览器 localStorage（官方为同目录 config.json）
- 新增演示模式、串口帧控制台、保护阈值一键读写
- 通信协议、命令帧、联机时序与官方完全一致，可混用

## 常见问题

- **联机失败/无应答**：确认波特率；换回官方上位机核对设备当前波特率；拔插 USB 后重试
- **浏览器不弹串口选择框**：确认用的是 Edge/Chrome，且不是 IE 模式
- **曲线不动**：设备仅在输出开启后电流才有读数；电压设定后需开启输出
- 详见同目录 `通信协议.md`
